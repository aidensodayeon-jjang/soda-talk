버튼 · LED · 스피커
스피커 배선
앰프 VDD → 5V
GND → GND
BCLK → GPIO5
LRC → GPIO3
DIN → GPIO44
OUT+ / OUT− → 스피커 + / −
버튼과 LED
버튼 한쪽 → GPIO4, 반대쪽 → GND
GPIO2 → 저항 → LED(+) → LED(−) → GND
실행 후 버튼을 누르고 있으면 LED가 켜지고, 놓으면 꺼집니다.
버튼 코드
GPIO4를 INPUT_PULLUP으로 설정합니다. 버튼을 누르면 LOW, 놓으면 HIGH가 됩니다.
