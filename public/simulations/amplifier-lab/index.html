3-1 · SODA CIRCUIT LAB
앰프 · 스피커 추가
1. 앰프 · 스피커 배치
LED와 버튼은 배선이 완료돼 있습니다. 앰프와 스피커도 배치돼 있으니, 상단 안내를 보고 앰프의 7개 선을 연결하세요.
2. 전원 · 신호선 연결
ESP32 5V → 빨강 + 레일
ESP32 GND → 파랑 − 레일
앰프 VDD → + 레일
앰프 GND → − 레일
BCLK → GPIO5
LRC → GPIO3
DIN → RX
OUT+ / OUT− → 스피커 + / −
버튼과 LED
버튼 한쪽 → GPIO4, 반대쪽 → 상단 − 레일
GPIO2 → 저항 → LED(+) → LED(−) → 상단 − 레일
기존 LED와 버튼의 연결은 그대로 유지됩니다.
음계 재생
배선이 끝나면 실행을 눌러 음계를 들어보세요. playTone의 주파수와 시간을 바꿀 수 있습니다.
